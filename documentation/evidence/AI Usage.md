# AI Assistance Disclosure

## AI Tool Used

**Tool:** ChatGPT (OpenAI)  
**Model:** GPT-6

ChatGPT was used as a learning and development assistant throughout this project. It helped me understand Terraform and Sentinel concepts, troubleshoot configuration issues, test security policies, integrate them with HCP Terraform, and prepare project documentation.

## Examples of Prompts Used

The following are representative examples of questions and requests made during development, rather than a complete conversation history:

- How can I configure AWS EC2 infrastructure using Terraform?
- How do I create Sentinel policies for digital sovereignty and infrastructure security?
- How can I test Sentinel policies using compliant and non-compliant mock data?
- Why am I getting errors when running Sentinel tests locally?
- Why are some Sentinel policies showing advisory violations instead of failing the entire run?
- How can I deliberately test EC2, storage, network, and sovereignty policy failures?
- How can I export Terraform plan output and save it as `tfplan`?

## Review and Verification

AI-assisted suggestions were reviewed and tested during development. Terraform configurations were checked using Terraform CLI commands, and all ten local Sentinel test cases passed. The policies were also evaluated through HCP Terraform, with screenshots and logs collected for both compliant and non-compliant scenarios.

The final configurations, testing evidence, and documentation were reviewed before submission.
